# Vault

Sistema personal de gestión del conocimiento construido con **Obsidian**.

## Estructura

* **Dashboard** — Punto de entrada al Vault.
* **01 Operations** — Gestión diaria: Inbox, Daily y Weekly.
* **02 Projects** — Proyectos de Work, Personal, Investigación y Emprendimiento.
* **03 Ideas** — Ideas por explorar o desarrollar.
* **04 Knowledge** — Conocimiento permanente.
* **05 Resources** — Recursos y material de referencia.
* **06 Personal** — Información y asuntos personales.
* **80 System** — Arquitectura, reglas, plugins y templates del Vault.
* **99 Archives** — Contenido archivado.

## Principio

> Capturar, organizar, desarrollar y conservar conocimiento en un sistema simple y portable.

La documentación del sistema se encuentra en **`80 System`**.
